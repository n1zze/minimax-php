# Публикация на shared хостинг

Пошаговая инструкция для выгрузки проекта на обычный хостинг (Beget, Reg.ru, Timeweb, Hostinger и т.д.).

---

## Требования к хостингу

| Требование | Минимум |
|------------|---------|
| PHP | 8.1+ |
| SQLite | Включена по умолчанию (pdo_sqlite) |
| mod_rewrite | Включён (для .htaccess) |
| Дисковое пространство | 500 МБ+ (зависит от загруженных файлов) |

Проверить можно в панели хостинга → PHP-настройки.

---

## Шаг 1: Собрать фронтенд локально

На своём компьютере:

```bash
cd minimax-php
npm install
npm run build
```

Появится папка `dist/` с готовыми файлами.

---

## Шаг 2: Подготовить файлы для загрузки

Тебе нужно загрузить на хостинг **всё кроме**:

```
НЕ загружать:
├── node_modules/      ← не нужен на сервере
├── src/               ← исходники React, не нужны
├── .mimocode/         ← настройки IDE
├── dist/              ← содержимое dist/ идёт в корень
├── package.json       ← не нужен
├── package-lock.json  ← не нужен
├── vite.config.js     ← не нужен
├── eslint.config.js   ← не нужен
├── scripts/           ← не нужен
├── screenshots/       ← не нужен
└── .git/              ← не нужен
```

### Что загружать в корень хостинга:

```
/
├── api/                  ← PHP-бэкенд
├── admin/                ← Админ-панель
├── assets/               ← из dist/assets/ (собранный JS/CSS)
├── data/                 ← БД (создастся автоматически)
├── public/               ← иконки, логотип
├── uploads/              ← загруженные файлы
├── config.php            ← ВАША конфигурация
├── .htaccess             ← настройки Apache
├── index.html            ← из dist/index.html
├── router.php            ← PHP-роутер
├── favicon.svg           ← из dist/
├── logo.svg              ← из dist/
├── icons.svg             ← из dist/
├── error404.html         ← страница ошибки
└── error500.html         ← страница ошибки
```

### Важно про dist/

Содержимое папки `dist/` нужно разместить **в корне** хостинга:

```
dist/index.html    →  /index.html
dist/assets/*      →  /assets/*
dist/favicon.svg   →  /favicon.svg
dist/logo.svg      →  /logo.svg
dist/icons.svg     →  /icons.svg
```

## Шаг 3: Загрузить на хостинг

### Через файловый менеджер (веб)

1. Зайди в панель хостинга
2. Открой файловый менеджер
3. Перейди в корневую папку сайта (обычно `public_html/` или `www/`)
4. Загрузи файлы

### Через FTP (FileZilla)

1. Скачай FileZilla: https://filezilla-project.org
2. Подключись к хостингу (данные FTP — в панели хостинга)
3. Перейди в корневую папку сайта
4. Перетащи файлы

---

## Шаг 4: Настроить права доступа

Через файловый менеджер хостинга или FTP:

| Папка/файл | Права | Зачем |
|------------|-------|-------|
| `data/` | 755 | База данных, логи |
| `uploads/` | 755 | Загруженные файлы |
| `config.php` | 644 | Конфигурация |

Как изменить права: правый клик → «Права доступа» или «CHMOD».

---

## Шаг 5: Настроить config.php

Открой `config.php` на сервере и **ОБЯЗАТЕЛЬНО** измени:

```php
// 1. Секретный ключ — сгенерируй свой!
//    Генератор: https://randomkeygen.com (раздел CodeIgniter Encryption Keys)
define('JWT_SECRET', 'ваш-уникальный-ключ-минимум-32-символа');

// 2. Пароль админа — придумай свой!
define('ADMIN_PASSWORD', 'ваш-надёжный-пароль');

// 3. Email админа
define('ADMIN_EMAIL', 'admin@yourdomain.com');

// 4. CORS — укажи свой домен
define('CORS_ORIGIN', 'https://yourdomain.com');

// 5. Пароль демо-проектов (если используете)
define('DEMO_PROJECT_PASSWORD', 'ваш-демо-пароль');
```

### ⚠️ Никогда не оставляй дефолтные пароли на продакшене!

---

## Шаг 6: Проверить

1. Открой `https://yourdomain.com` — должен загрузиться сайт
2. Открой `https://yourdomain.com/admin/` — админ-панель
3. Войди с email/password из `config.php`
4. Создай проект, загрузи файл — проверь что всё работает

## Если что-то не работает

### Белый экран / 500 ошибка

1. Проверь `data/app.log` — там логи ошибок
2. Проверь права на папки `data/` и `uploads/` (должны быть 755)
3. Проверь что PHP 8.1+ (в настройках хостинга)

### API возвращает 404

1. Проверь что mod_rewrite включён (Apache)
2. Проверь что `.htaccess` загружен на сервер
3. В панели хостинга: Apache → включить AllowOverride All

### Файлы не загружаются

1. Проверь что папка `uploads/` существует и имеет права 755
2. Проверь лимит `upload_max_filesize` в настройках PHP (нужно ≥ 50MB)
3. Проверь лимит `post_max_size` (нужно ≥ 50MB)

### "Database is locked"

SQLite может блокироваться при одновременных запросах. Решение:
1. Удали `data/mimimax.db-wal` и `data/mimimax.db-shm`
2. Проверь права на `data/` (755)

## Обновление на сервере

1. Сделай бэкап через `/admin/backup.php`
2. Скачай папку `uploads/` (на всякий случай)
3. Собери новую версию локально: `npm run build`
4. Загрузи новые файлы (кроме `config.php`, `data/`, `uploads/`)
5. Проверь сайт

---

## Бэкап

### Через админ-панель

1. Открой `/admin/backup.php`
2. Нажми «Скачать бэкап»

### Вручную

Скачай через FTP:
- Файл `data/mimimax.db` — база данных
- Папку `uploads/` — все загруженные файлы
- Файл `config.php` — конфигурация
