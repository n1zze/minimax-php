# Mimimax

Платформа для дизайн-студий: управление проектами, загрузка файлов, доступ клиентов и визуализаторов.

## Технологии

- **Фронтенд:** React 19, Vite, Zustand, React Router
- **Бэкенд:** PHP 8.1+, SQLite (PDO), JWT
- **Хостинг:** Любой shared хостинг с PHP

## Быстрый старт (локально)

### 1. Установить зависимости фронтенда

```bash
npm install
```

### 2. Собрать фронтенд

```bash
npm run build
```

Собранные файлы попадут в `dist/`. Скопируйте содержимое `dist/` в корень проекта (или настройте Vite на сборку в корень).

### 3. Настроить конфигурацию

Скопируйте `config.example.php` → `config.php` и отредактируйте:

```php
define('JWT_SECRET', 'ваш-секретный-ключ-минимум-32-символа');
define('ADMIN_EMAIL', 'admin@yourdomain.com');
define('ADMIN_PASSWORD', 'ваш-надёжный-пароль');
define('CORS_ORIGIN', 'https://yourdomain.com');
```

### 4. Запустить локальный сервер

```bash
php -S localhost:8080 router.php
```

Откройте http://localhost:8080 в браузере.

## Деплой на shared хостинг

### Шаг 1: Подготовить файлы

1. Выполните `npm run build` локально
2. Скопируйте содержимое `dist/` в корень проекта (поверх `index.html`)

### Шаг 2: Загрузить на хостинг

Загрузите на хостинг через FTP или файловый менеджер:

```
/
├── api/                  ← PHP бэкенд
├── admin/                ← Админ-панель
├── data/                 ← БД (создаётся автоматически)
├── uploads/              ← Загруженные файлы
├── config.php            ← ВАША конфигурация
├── .htaccess             ← Настройки Apache
├── index.html            ← Точка входа SPA
├── assets/               ← Собранный JS/CSS
├── public/               ← Иконки, логотип
└── error404.html         ← Страница ошибки
```

### Шаг 3: Настроить права доступа

Через файловый менеджер хостинга или SSH:

```
data/       → 755 (или 777 если 755 не работает)
uploads/    → 755 (или 777)
config.php  → 644
```

### Шаг 4: Настроить config.php

Отредактируйте `config.php` на сервере:

```php
// Сгенерируйте: https://randomkeygen.com (Section: CodeIgniter Encryption Keys)
define('JWT_SECRET', 'уникальный-ключ-для-вашего-сайта');

// Ваши реальные данные
define('ADMIN_EMAIL', 'admin@yourdomain.com');
define('ADMIN_PASSWORD', 'надёжный-пароль');

// Ваш домен
define('CORS_ORIGIN', 'https://yourdomain.com');
```

### Шаг 5: Проверить

1. Откройте `https://yourdomain.com` — должен загрузиться сайт
2. Откройте `https://yourdomain.com/admin/` — админ-панель
3. Войдите с email/password из config.php
4. Создайте проект, загрузите файл — проверьте что всё работает

## Админ-панель

Откройте `/admin/` в браузере. Позволяет:

- Просматривать список проектов
- Сбрасывать пароли клиентов и токены визуализаторов
- Удалять проекты
- Скачивать бэкап базы данных

## Бэкап

1. Откройте `/admin/backup.php`
2. Нажмите «Скачать бэкап»
3. Также скопируйте папку `uploads/` для полного бэкапа

## Логи

Логи пишутся в `data/app.log`. Если что-то не работает — откройте этот файл в текстовом редакторе.

## Обновление

1. Сделайте бэкап через `/admin/backup.php`
2. Скачайте папку `uploads/`
3. Загрузите новые файлы (кроме `config.php` и `data/`)
4. Проверьте сайт

## FAQ

**Q: Забыл пароль админа**
A: Отредактируйте `ADMIN_EMAIL` и `ADMIN_PASSWORD` в `config.php`, удалите файл `data/mimimax.db`, обновите страницу — БД пересоздастся с новыми данными.

**Q: Белый экран**
A: Проверьте права на папки `data/` и `uploads/`. Проверьте `data/app.log` на ошибки.

**Q: Файлы не загружаются**
A: Проверьте что папка `uploads/` существует и имеет права 755. Проверьте лимит `upload_max_filesize` в настройках PHP хостинга.

**Q: API возвращает 404**
A: Убедитесь что mod_rewrite включён в Apache. Проверьте что `.htaccess` загружен на сервер.
